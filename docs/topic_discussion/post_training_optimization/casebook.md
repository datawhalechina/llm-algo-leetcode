# 后训练优化判断手册 | Post-Training Casebook

先根据失败现象、训练信号和已有测量选择下一步，再由所需数据与更新方式定位算法。每次判断至少记录数据版本、模型版本、配置、工作负载、质量指标、资源消耗、失败样本、输出文件和最终决定。
