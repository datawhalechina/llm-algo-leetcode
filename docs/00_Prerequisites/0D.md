# Group 0D: Transformer Block Dataflow and Component Basics | 0D: Transformer Block 数据流与组件基础

## Group Overview | 组概览

一个 Transformer Block 通过 Attention 和 MLP 两个分支更新隐状态，两次残差相加都要求形状对齐。本组先看完整 Block，再分别观察激活、归一化与 Attention 怎样计算输出。
