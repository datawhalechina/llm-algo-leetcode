# Group 0A: Python, NumPy, and Engineering Entry | 0A: Python、NumPy 与工程入口

本组学习后续 Notebook 会反复使用的数据结构、数组维度、对象状态，以及配置和文件路径。

## Group Overview | 组概览

按“数据与函数 → 数组与维度 → 对象状态 → 配置与文件”学习。完成后，你应能检查函数输入、解释数组形状变化、更新对象中的累计指标，并找到一次运行的输入、缓存和输出文件。

03 与 04 都会出现“状态”，但管理范围不同：

| 页面 | 管理对象 | 状态位置 | 典型操作 |
|:---|:---|:---|:---|
| 03 | 对象内部字段与生命周期 | Python 对象实例 | 校验不变量、更新、查询、重置 |
| 04 | 一次运行的外部条件与产物 | config、路径、manifest、artifact | 合并配置、定位资源、登记输入输出与运行身份 |

## Learning Path | 学习路径

### Recommended Order | 推荐顺序

- 按 [01](./01_Python_Essentials_for_LLM.md) → [02](./02_NumPy_and_Einsum.md) → [03](./03_Python_OOP_and_Utility_Patterns.md) → [04](./04_Python_Config_and_Data_Entry.md) 阅读：先检查数据与函数输入，再处理数组维度，随后维护跨调用状态，最后组织配置、路径和运行产物。若要尽快进入 Part 2，优先完成 01、02；需要阅读模型对象或复现实验时，再补 03、04。

### Next Steps | 后续衔接

- 完成本组后进入 [0B](./0B.md)，把数组表达转换为 Tensor、layout 和 Autograd 中的张量表达。遇到 shape 问题回看 02，遇到对象状态问题回看 03，遇到配置或 artifact 追踪问题回看 04。

如果已经熟悉 Python 和 NumPy，可以直接用各页验证题检查自己的函数、shape 和运行记录习惯，再进入 0B。
