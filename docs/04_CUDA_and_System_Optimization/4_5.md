# Group 4.5: Implementation and Hardware Decisions | 4.5: 实现方式与硬件选型

局部内核更快，不一定抵消转换与准备成本；报价更低，也不一定满足工作集和服务要求。本组先比较改写对完整调用的影响，再筛硬件可行性和同业务量成本，两页都允许“保留现有方案”或“证据不足，继续验证”，不按语言或显卡型号给固定排名。

## Learning Path | 学习路径

### Recommended Order | 推荐顺序

- 尚未确定实现方式时，先读[18](./18_CUDA_vs_Triton_vs_PyTorch.md)，判断目标是否占关键路径、上层路径是否足够、准备能否摊销。
- 已有可运行候选并准备选硬件时，可直接读[19 TCO与硬件选择](./19_TCO_and_Hardware_Selection.md)，先排除容量或服务要求不满足的方案，再比较相同周期、相同业务产出下的成本；证据不再适用时先复测。
- 两页没有结果文件依赖。18的阶段耗时、19的性能和价格均为构造输入；换成真实候选后，应使用相同负载、统计范围和计费条件的记录，不把教学情景登记成实测结论。

### Prerequisites | 按需前置

- [Part01·09 图编译](../01_Hardware_Math_and_Systems/09_AI_Compilers_and_Graph_Optimization.md)：选择18时区分图级优化与内核实现。
- [Part01·33 TCO与成本模型](../01_Hardware_Math_and_Systems/33_TCO_and_Cost_Model.md)：选择19时统一观察期和合格业务产出。

### Next Steps | 后续衔接

- 部署位置、实例组合与扩容条件进入[部署与异构路线](../topic_discussion/deployment_heterogeneous/intro.md)；独立综合复测按[Part05项目](../05_Integrated_Projects_and_Decisions/intro.md)选择。

## Environment Notes | 环境说明

18使用阅读与手算，19使用基础CPU环境运行标准库决策练习，均无需GPU。真实候选的测量与环境应在相应实现或项目中准备；19不提供实时设备报价或固定型号推荐。
