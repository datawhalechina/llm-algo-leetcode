# Group 4.2: Tiled Compute and Data Reuse | 4.2: 分块计算与数据复用

矩阵乘法可以把输入子块搬入片上反复使用，也可以沿K维安排加载与计算的轮换。本组先看共享内存GEMM与WMMA的两种计算组织，再区分主机传输的理想阶段模型和设备内的线程级异步拷贝；两类流水的搬运范围和同步方式不同。

## Group Asset Overview | 组内资产总览

| 页面 | 核心问题 | 实现与证据产物 | 何时进入 |
|:---|:---|:---|:---|
| [06 共享内存GEMM](./06_CUDA_Shared_Memory_Optimization.md) | 线程怎样协作装载，并保护读取和覆盖？ | 方阵、边缘、跨K累加与当前流数值核对 | 理解块内子块复用 |
| [07 Tensor Core MMA](./07_Tensor_Core_MMA_Programming.md) | 输出子块、矩阵片段与K维累加怎样配合？ | CPU网格计划；GPU WMMA数值、对齐与当前流核对 | 需要观察矩阵片段编程 |
| [08 异步预取与双缓冲](./08_Async_Data_Prefetch_and_Double_Buffering.md) | 首尾阶段与较慢阶段怎样限制流水时间？ | CPU串行／流水估算与槽位条件，不执行CUDA | 先分析主机传输与设备计算的理想安排 |

## Learning Path | 学习路径

### Recommended Order | 推荐顺序

- **计算复用：** 从[06](./06_CUDA_Shared_Memory_Optimization.md)观察普通线程如何装载、计算和同步；需要矩阵片段时再读[07](./07_Tensor_Core_MMA_Programming.md)。两页分别实现自己的输入与内核，不读取对方输出。
- **流水与缓冲：** [08](./08_Async_Data_Prefetch_and_Double_Buffering.md)用CPU模型解释填充、稳态、排空和槽位寿命；[09](./09_CUDA_Async_Copy_Pipeline.md)把关注点转到内核里的拷贝与等待。可先理解模型再选择实现，但08不是09的计时结果，也不是同一代码的前一个版本。
- WMMA数值正确不等于已经采集到实际矩阵指令或吞吐；异步拷贝接口可运行也不等于已测得搬运与计算重叠。相应性能问题需要单独测量。
