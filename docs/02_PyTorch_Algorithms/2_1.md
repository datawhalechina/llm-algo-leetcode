# 2.1 解码器基础组件与注意力 | Decoder Components and Attention Basics

文本先变成词元编号和向量，再经过归一化、前馈网络与注意力计算。本组逐个观察这些组件：输入是什么形状、怎样计算、输出怎样交给下一步；位置编码与头的分组又怎样改变注意力读取历史的方式。随后在2.2把组件组装成模型块，并研究专家和长序列记忆。

## 阅读顺序

先读00，认识词元向量、形状与梯度。01解释归一化，02解释门控前馈，两者可以分别学习；03补充位置编码，再读04理解查询头怎样使用KV头。需要继续比较压缩后的历史表示时，进入2.2的[ARCH-MLA MLA 与紧凑 KV 表示](./ARCH-MLA_Multihead_Latent_Attention.md)，再按项目71的具体模型与后端准备对照。

```text
00 输入状态
├─ 01 归一化 ─┐
├─ 02 门控 FFN ├─→ 2.2 模型块与架构分支
└─ 03 位置编码 → 04 注意力表示 ─┘
```
