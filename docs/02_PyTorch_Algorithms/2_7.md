# Group 2.7: Advanced Inference Strategies | 2.7：高级推理策略

本组聚焦生成加速、缓存复用与多请求 Serving。学习路径先区分投机式生成和 Cache 复用，再进入 Chunked Prefill、Decode 调度、PD 分离与异构资源决策。

## Group Overview | 组概览

这一组围绕“怎样减少生成等待、重复计算和服务争用”展开：23、35 构成投机式生成策略链；22、24、34 构成 Cache 复用链；36–39 则把单步调度推进到 Chunked Prefill、PD 分离与异构服务决策。

本组非项目页统一沿用 `26` 的 notebook-first 结构，组页只负责阅读路径与资产导航。
