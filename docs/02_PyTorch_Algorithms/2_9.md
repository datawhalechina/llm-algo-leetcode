# Group 2.9: Distributed Parallel Strategy | 2.9: 分布式并行策略

本组聚焦 ZeRO、Pipeline 和 Tensor Parallelism，目标是理解大模型训练规模化的并行边界，并为 `2.10` 里的 `79 -> 80 -> 81` 通信并行项目线提供上游基础。

## Group Overview | 组概览

这一组把分布式并行的核心策略讲清楚，是进入项目实战之前的并行基础层。阅读顺序和组内资产见下表，先看 27，再进入 28-29；MoE 专家并行扩展页 47 和通信 profiling 扩展页 46 已完成，可在三类并行策略之后继续看，并继续承接到 `2.10` 的 [79](./79_Distributed_Parallel_Benchmark.md) -> [80](./80_MoE_Expert_Parallel_Benchmark.md) -> [81](./81_Distributed_Inference_Project.md)。若训练并行之外还要继续看训练内存账本，可回看 [43](./43_Unified_Memory_Management.md) 和 [75](./75_Memory_Budget_Compression_Project.md)；自动调优见[算子优化 Task5](../topic_discussion/operator_optimization/05_cost_model_and_profiling.md)，通信与并行的后续补页再看 [48](./48_Communication_Hotspots_and_Mitigation.md) -> [49](./49_Parallelism_Strategy_Selection.md)。
