# 2.2 模型架构 | Model Architecture

归一化、注意力和前馈组件怎样连成可以反复堆叠的模型块？在这个基础上，增加专家或改变历史保存方式，又会改变哪些计算？本组先组装模型块，再沿配置核对、混合专家（MoE）和长序列记忆分支学习，最后选择对应项目比较具体模型与负载。

## 机制学习路径

- **模型块与配置：** 05 → 08。先确认残差连接和组件位置，再检查声明的层数、维度与共享参数是否对应实际模块。
- **MoE 容量：** 05 → 06 → 07。路由器选择专家，专家容量决定哪些词元被接收，负载反馈再影响路由学习；跨设备分发与通信继续进入[2.9 通信与并行](./2_9.md)。
- **注意力表示与访问：** 04 → ARCH-MLA；03 → 44。前一条改变保存什么状态，后一条改变历史中哪些位置可见。
- **递推与混合记忆：** 44 → 45 → ARCH-HYBRID-MEMORY。先理解有限访问范围，再比较固定状态和显式历史，最后进入层级混合。
