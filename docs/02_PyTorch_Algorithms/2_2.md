# Group 2.2: Model Architecture | 2.2: 模型架构

本组解决“怎么把单个算子组装成完整模型，并理解结构怎样改变记忆方式”的问题，重点是 Block、Router、Attention 访问与递推状态。

## Group Overview | 组概览

本组从完整 Decoder Block 出发，沿三条架构分支展开：一条讨论 Dense FFN 如何走向 MoE 的容量与路由设计；一条讨论 Attention 中 KV 的表示与可访问范围；另一条比较完整 token 历史与递推状态。它连接基础组件与后续训练、推理和架构选型。

## Learning Path | 学习路径

### Recommended Order | 推荐顺序

先阅读 [05](./05_LLaMA3_Block_Tutorial.md)，确认 Norm、Attention、FFN 和残差如何构成一个 Decoder Block；需要比较结构选择时，接着进入 [60](./60_Decoder_Block_Stability_Benchmark.md)，再按目标选择一条分支。

- **容量与稀疏化分支**：[06](./06_MoE_Router.md) → [07](./07_MoE_Load_Balancing_Loss.md) → [08](./08_Architecture_Tricks.md)。从 token 如何选择专家，走到负载、容量与溢出，再把 Dense/MoE、权重共享和模块配置写成可审计的结构取舍。
- **Attention 表示与访问分支**：先完成 [04 Attention（MHA / GQA）](./04_Attention_MHA_GQA.md) → [ARCH-MLA](./ARCH-MLA_Multihead_Latent_Attention.md)，区分“减少 KV heads”和“压缩历史表示”；再阅读 [44](./44_Local_Sliding_and_Sparse_Attention.md) → [78](./78_Attention_Access_Pattern_Benchmark.md)，把表示选择与访问范围分开验证。71 继续承担 MLA 项目证据，不替代机制页。
- **长序列记忆分支**：完成 04、44 后阅读 [45](./45_Linear_Attention_and_Recurrent_State.md) → [ARCH-HYBRID-MEMORY](./ARCH-HYBRID-MEMORY_Attention_SSM_Hybrid.md) → [77](./77_Long_Sequence_Memory_Architecture_Benchmark.md)。这一分支先建立递推状态，再明确 Attention / SSM 的层级分工，最后用长度阶梯记录质量和成本证据。

### Next Steps | 后续衔接

- 看完本组后，可进入 [2.3](./2_3.md)，把模型结构接到微调、训练和闭环实验；若要从设计取舍继续向前，可进入大模型架构演进专题的 Attention 表示、访问范围、MoE 与混合记忆任务，并用 [61](./61_Model_Architecture_Exploration.md) 完成结构审计项目。
