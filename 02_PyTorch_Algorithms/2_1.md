# Group 2.1: Decoder Components & Attention Basics | 2.1: Decoder 基础组件与注意力

本组从模型输入到 Attention 建立现代 Decoder 的组件链：token 如何成为 hidden state，LayerNorm 如何收敛为 RMSNorm，单路 FFN 如何走向门控 MLP，位置如何进入 Q/K，以及 Attention 如何通过 head 与 KV 表示读取上下文。

## Group Overview | 组概览

本组先建立每个组件的输入、输出、状态与资源含义，并指出现代 Decoder 为什么采用这些替换；下一组再把它们组装为完整 Block，并比较不同架构如何重新组织这些组件。推荐先建立输入与梯度契约，再沿 Norm / FFN、位置编码和 Attention 的路径阅读。

## Learning Path | 学习路径

### Recommended Order | 推荐顺序

- [00](./00_PyTorch_Warmup.ipynb) 建立输入与梯度契约；
- [01](./01_RMSNorm_Tutorial.ipynb) 与 [02](./02_SwiGLU_Activation.ipynb) 分别理解 Block 的 Norm / MLP 支路；
- [03](./03_RoPE_Tutorial.ipynb) → [04](./04_Attention_MHA_GQA.ipynb) 沿 Q/K 位置关系进入 Attention、head 组织和 KV 表示；需要继续比较 MLA 的 latent KV 表示时，进入项目 [71](./71_MLA_KV_Cache_Architecture_Benchmark.ipynb)。

### Next Steps | 后续衔接

- 进入 [2.2](./2_2.md) 组装完整模型结构；也可按模型架构演进专题继续阅读 Task0 的输入/Block 主干、Task1 的 Attention 表示、Task2 的 Norm/FFN 与 Task3 的位置编码。
