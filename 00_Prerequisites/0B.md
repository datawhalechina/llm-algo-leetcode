# Group 0B: PyTorch Tensors and Autograd | 0B: PyTorch 张量与自动求导

## Group Overview | 组概览

形状相同的张量可能拥有不同布局，也可能共享同一份存储；前向结果正确时，梯度仍可能被切断或意外累积。本组从张量属性和索引开始，追踪反向传播以及梯度的保存、清理与关闭。

![0B 张量、布局、反向传播与梯度控制的阅读路线](../docs/public/00_Prerequisites/0b_tensor_autograd_map.svg)

## Learning Path | 学习路径

### Recommended Order | 推荐顺序

按 05 → 06 → 07 → 08 阅读。形状或索引错误先查 05、06；梯度缺失、重复累积或冻结异常先查 07、08。
