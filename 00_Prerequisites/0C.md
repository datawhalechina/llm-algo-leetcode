# Group 0C: PyTorch Model Construction | 0C: PyTorch 模型构建

本组把 Tensor 和 Autograd 接到 `nn.Module`、Optimizer、Loss 与 DataLoader。学习者将沿着模型参数注册、前向调用、状态保存、反向更新和 batch 输入这条路径阅读训练代码，并能判断每个对象在训练闭环中的职责。

## Group Overview | 组概览

这一组按“模型对象 → 状态保存 → 参数更新 → batch 契约”的顺序展开：先定位模型参数和 `forward()` 入口，再理解状态如何保存，随后看 loss、梯度和 optimizer 如何更新参数，最后把样本组织成训练循环可以消费的 batch。

对 Part 2 来说，这一组先补的是模型代码怎么组织、怎么调用、怎么保存的语法桥：`nn.Module`、`forward()`、`parameters()`、`named_parameters()`、`state_dict()`、`load_state_dict()`、`zero_grad()`、`optimizer.step()`、`loss.backward()`，以及把模型参数、输入 batch 和训练步对齐的最小读法。

完成这些接口检查后，再去 0D 分析激活函数、归一化和 Attention 为什么这样设计。

## Learning Path | 学习路径

### Recommended Order | 推荐顺序

- 按 [09](./09_PyTorch_nn_Module_Basics.ipynb) -> [10](./10_PyTorch_State_dict_and_Persistence.ipynb) -> [11](./11_PyTorch_Optimizers_and_Loss.ipynb) -> [12](./12_PyTorch_Minimal_Training_Interface.ipynb) 阅读：先看模型对象，再看状态保存，接着看参数更新，最后看数据如何形成 batch。这样每一页都会回答训练闭环中的一个不同问题。

### Part 2 重点 | Part 2 Focus

- [09](./09_PyTorch_nn_Module_Basics.ipynb)：先补 `nn.Module`、参数注册、`forward()` 入口，解决“模型代码从哪里开始读”的问题。
- [10](./10_PyTorch_State_dict_and_Persistence.ipynb)：先补 `state_dict()`、`load_state_dict()`、checkpoint 和保存边界，解决“参数怎么保存和恢复”的问题。
- [11](./11_PyTorch_Optimizers_and_Loss.ipynb)：先补 `loss.backward()`、`zero_grad()`、`optimizer.step()`，解决“训练步怎么闭环”的问题。
- [12](./12_PyTorch_Minimal_Training_Interface.ipynb)：先补 `Dataset / DataLoader / batch` 契约，解决“数据怎么喂进训练循环”的问题；如果后面开始做 SFT 或其他监督微调，这一页也会帮助你看懂样本如何对齐成训练 batch。
