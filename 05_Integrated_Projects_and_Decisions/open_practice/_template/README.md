# 开放实践项目文件夹模板

复制本目录并重命名为 `X01_<主题>` 或 `X02_<主题>`，再按实际项目补全内容。编号在目标、工作负载和运行入口确定后分配；尚未确定的方向不建立空项目页。

建议目录：

```text
X01_<主题>/
├── index.md                    # 项目问题、范围、环境与运行顺序
├── project_config.example.yaml # 唯一配置入口；不保存密钥或本地绝对路径
├── Project.ipynb               # 预检、准备、实验、核对、结论
└── assets/                     # 仅保存项目必需的小型静态资产
```

Notebook 的实际阶段由实验决定，不必照搬固定阶段名。正式实验前应能从配置和说明中确认：代码/模型版本、数据来源与切分、目标硬件与环境、资源预算、质量门槛、结果路径及失败后的处理方式。大型权重、数据集、缓存和临时日志放在项目目录外的缓存或结果目录中，并在结果中登记版本或哈希。

Part 05 的开放实践项目应给出可复跑的基线、至少一个候选、质量或正确性检查、资源记录和结论边界。若项目形成了稳定的跨专题交付链，再评估是否纳入核心交付项目；不要仅因涉及新模型或新框架就升级为核心项目。
